# Rental Busana Adat dan Kostum

## Deskripsi

Rental Busana Adat dan Kostum merupakan aplikasi berbasis Java yang
dibuat untuk memenuhi tugas Ujian Akhir Semester (UAS) Praktikum
Pemrograman Berorientasi Objek (PBO). Aplikasi ini menyediakan sistem
penyewaan berbagai jenis busana, meliputi baju adat, kostum
karakter/cosplay, serta busana pengantin/pesta. Sistem juga mendukung
pengelolaan barang, akun pengguna, transaksi penyewaan, beberapa metode
pembayaran, invoice, dan perhitungan denda keterlambatan.

## Cara Compile dan Menjalankan Program
Prasyarat
- Pastikan Java Development Kit (JDK) sudah terpasang.
- Periksa instalasi Java dengan perintah:
javac rental/*.java
java rental.Main
- Jalankan perintah diatas dari folder utama (Main.java)
